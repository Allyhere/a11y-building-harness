# Context

**verify** — fail-closed axe-core scan of a live URL in Chromium. Exit 0 = no violations; 1 = violations or runtime error; 2 = bad usage or disallowed URL.

**blueprint** — compact APG reminder card (native HTML / kit first). Aliases: `modal` → `dialog`.

**fixture** — demo `/` should pass the harness axe tags; `/broken` must fail (`image-alt`, `label`). Clone-only; not in the npm tarball.

**allow-remote** — `verify` flag. Default is loopback http(s). Never opens `file:` or link-local/metadata hosts.
